# Hot Potato Game Manager

Hot Potato Game Manager is a Dalamud plugin for Final Fantasy XIV that helps manage a party-based Hot Potato dice game.

## Features

- Tracks participating players
- Generates randomized Hot Potato numbers
- Detects player dice rolls
- Automatically identifies Hot Potato hits
- Manages player elimination
- Tracks rounds and turn order
- Adds additional Hot Potato numbers as rounds progress
- Provides party chat announcements
- Tracks game state through an in-game interface

## Usage

Open the plugin with:

/hotpotato

Add the participating players and configure the game from the Hot Potato Game Manager window.

Players take turns using `/dice party`. If a player's roll matches one of the active Hot Potato numbers, that player is eliminated.

After an elimination, a new round begins and additional Hot Potato numbers are added to the existing pool.

The game continues until one player remains.

## Requirements

- XIVLauncher
- Dalamud
